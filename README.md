# ThePrime

A multi-page marketing website for a virtual assistant services agency, built with plain HTML, CSS and JavaScript.

**Live demo:** https://theprime-kappa.vercel.app

## Key Features

- Pages: Home, Services, Industries, Pricing, About, Values, FAQ and Contact
- Separate landing pages for Real Estate, Roofing and Construction, and Entrepreneurs
- Responsive layout with a mobile menu and dropdown navigation
- Sticky header on scroll
- Industries slider
- FAQ accordion
- Client-side form validation on the contact and pricing forms
- Smooth scrolling and scroll-triggered animations
- Lazy-loaded images

No framework or build step is used.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Vercel (hosting)

## Getting Started

```bash
git clone https://github.com/majidawan01/ThePrime.git
cd ThePrime
```

Open `index.html` in a browser, or serve the folder with any static server, for example the VS Code Live Server extension.
